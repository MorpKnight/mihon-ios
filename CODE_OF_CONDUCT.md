# Code of Conduct

## Our Standard

We want this project to be welcoming, respectful, and productive.

Examples of behavior that help:

- being respectful in disagreements
- assuming good intent
- giving actionable, specific feedback
- focusing criticism on code and design, not people

Examples of unacceptable behavior:

- harassment or discrimination
- personal attacks
- deliberately hostile or dismissive communication
- publishing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and pull requests that violate this code of conduct.

## Scope

This code of conduct applies in repository discussions, issues, pull requests, and other project communication spaces.
